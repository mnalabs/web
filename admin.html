El panell encara no està connectat

Perquè els canvis es guardin i els vegi tothom, el panell necessita un projecte de Supabase. Mentrestant, la web mostra els paquets per defecte.

  1. Crea un projecte nou a supabase.com. No facis servir el de lliga.cat.
  2. A SQL Editor, executa el codi del fitxer CONFIGURAR-PANELL.md.
  3. A Authentication › Users, afegeix l'usuari equip.lliga.cat@gmail.com amb la contrasenya que vulgueu.
  4. Copia l'URL i la clau anon de Project Settings › API a assets/config.js i torna a publicar la web.
